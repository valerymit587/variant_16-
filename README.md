# Инструмент визуализации графа зависимостей (Вариант 16)

## Описание
Программа на Python для построения графа зависимостей пакетов (формат Alpine Linux apk). Использует алгоритм DFS с рекурсией.

## Параметры командной строки
- `--package` — имя пакета
- `--repo` — путь к тестовому файлу
- `--test-mode` — включить тестовый режим
- `--depth` — максимальная глубина
- `--output` — имя файла для сохранения

## Запуск
```bash
python main.py --package A --repo test_repo.txt --test-mode --depth 3
